# Lab 4 – Multi-Agent Defensive Workflow

**Goal:** Implement a multi-agent workflow where one agent rewrites unsafe queries before passing them to the main agent.

## Workflow

```
User query → [Rewriter Agent] → sanitized query → [Answer Agent] → Response
```

## Requirements

- Minimum 2 agents in sequential workflow
- At least one agent performs query rewriting
- Log/document original query, rewritten version, and final response

## Stack

- Framework: Microsoft Agent Framework
- Containerization: Docker
